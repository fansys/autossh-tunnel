info 系统架构与特性

SSH Tunnel Manager 是一个基于 Go 原生 SSH 库与 Tailwind CSS 构建的高性能、一体化（All-in-One）SSH 隧道管理工具。系统零外部系统依赖，单容器或单一二进制即可自包含运行。

🚀 纯 Go 原生 SSH 引擎
基于官方 golang.org/x/crypto/ssh 构建，无需安装 autossh 或 sshpass，单隧道仅占用几 KB 内存。
🔄 三种转发模式全支持
完整支持 远程到本地 (-L)、本地到远程 (-R) 和 动态 SOCKS5 代理 (-D)。
🔐 私钥 Write-Only 安全机制
页面粘贴私钥后自动写入 0600 权限文件，接口与前端绝不回显私钥明文。
📊 实时时延与流量监控
毫秒级 RTT 延迟检测、实时 Tx/Rx 吞吐量统计与活跃连接数监控。

rocket_launch 极简部署指南

方式 1：Docker Compose 一键启动 (推荐)
services:
  autossh:
    image: ghcr.io/fansys/autossh-tunnel:latest
    container_name: autossh-tunnel
    volumes:
      - ./config:/etc/autossh:rw
    environment:
      - TZ=Asia/Shanghai
      - PORT=8080
      - USERNAME=admin
      - PASSWORD=admin888
    network_mode: "host"
    restart: always
方式 2：单一可执行文件运行 (True Single Binary)
./autossh-server

自动初始化当前目录下的 ./config/config.yaml 并通过内嵌资源启动 Web 控制台。

troubleshoot 常见故障排查

1. SSH 密码认证失败 (attempted methods [none password])
• 确认远程主机是否带有用户名（例如必须为 username@host，未提供时默认使用 root）；
• 若使用 root 登录，很多现代 Linux 默认禁止 root 密码登录（PermitRootLogin prohibit-password），请改用普通用户或改用 SSH 密钥认证。
2. 主机公钥指纹未受信 (Host Key Verification Failed)
• 可在隧道的高级选项中将 StrictHostKeyChecking 设置为 accept-new（自动信任首次连接主机公钥）。
